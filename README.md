##  Descripción
Kindor Fiesta es una aplicación desarrollada para facilitar la organización de eventos y celebraciones infantiles.  
Permite gestionar reservas, proveedores y actividades de manera práctica y ordenada.

**-Notas del Desarrollo**

Durante el proceso de desarrollo del sitio web **KINDERFIESTA**, se buscó implementar un sistema web funcional, dinámico y accesible tanto para administradores como para usuarios finales.  

**- Uso de las Tecnologías**

Para el desarrollo del sitio web **KINDERFIESTA**, se emplearon diversas tecnologías que hicieron posible construir un sistema completo y eficiente:

- **PHP:**  
  Utilizado como lenguaje principal del lado del servidor. Gracias a PHP se manejó la lógica del sistema, la conexión con la base de datos y las operaciones dinámicas como el registro, visualización y actualización de información sobre los salones, calificaciones y comentarios.

- **MySQL (mediante XAMPP):**  
  Utilizado para la gestión y almacenamiento de datos. MySQL permitió crear y mantener la base de datos que guarda información de usuarios, roles, salones, fotos y calificaciones.  
  XAMPP proporcionó el entorno local para ejecutar el servidor **Apache** y la base de datos, permitiendo una conexión estable y eficiente con el sistema web.

- **HTML y CSS:**  
  Se usaron para estructurar y diseñar las páginas del sitio. **HTML** permitió definir la disposición y contenido de cada elemento, mientras que **CSS** mejoró la presentación visual y la experiencia del usuario a través de un diseño atractivo y adaptable.

- **JavaScript y AJAX:**  
  Implementados para aportar dinamismo e interactividad. **JavaScript** permitió controlar acciones como apertura y cierre de modales, validación de formularios, carga de reseñas y envío de comentarios.  
  **AJAX** fue clave para actualizar secciones del sitio (como el promedio de estrellas o los comentarios) sin recargar toda la página, brindando una experiencia más fluida.

- **GitHub:**  
  Se utilizó como plataforma de control de versiones y colaboración. A través de GitHub, el equipo pudo trabajar de manera remota, compartir avances, revisar código y mantener un respaldo constante del proyecto.

---

**-Solución de Problemas con el Sistema**

El sitio web fue diseñado para resolver distintos problemas que enfrentaban tanto los administradores de salones como los usuarios:

- **Falta de información centralizada:**  
  Antes, los datos sobre los salones estaban dispersos o desactualizados. Con este sistema, los usuarios pueden acceder a toda la información desde un solo lugar, incluyendo nombre, descripción, teléfono, dirección y ubicación exacta mediante un botón que redirige a **Google Maps**.

- **Ausencia de valoraciones visibles:**  
  Los clientes no podían conocer la calidad del servicio antes de contratar un salón.  
  Con KINDERFIESTA, ahora pueden consultar **reseñas y calificaciones** de otros usuarios, lo que genera mayor confianza y transparencia.

- **Gestión manual de salones:**  
  El sistema permite a los administradores **agregar, editar o eliminar salones** desde un panel de administración fácil de usar, agilizando las tareas de mantenimiento y actualización de información.
